# About the Game
*Just One More Server* is a top-down maze stealth game. The player's objective is to steal all the servers for a data centre, sneaking around guards that will chase them out. The player navigates through obstacles while also avoiding cameras that signal the player's location to the guards. The player must also chase down janitors who hold keys to grant access to certain areas of the map. As the player steals from each server, they construct a code which unlocks the door to the final server. Once the final server is nabbed, the game turns into a fast escape with permanently alerted guards.

# Final Game (Assignment 3)
All the source code, game files, and executables for the final version of *Just One More Server* are located on the `main` branch. 

Game builds can be found under the `BUILDS/` directory. For example, to launch the game on Windows, clone the repository and open `CISC486_Group_5_Project/BUILDS/WINDOWS/JustOneMoreServer_x64/CISC486_Group_5_Project.exe`.
