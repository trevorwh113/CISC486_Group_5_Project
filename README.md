# About the Game
*Just One More Server* (working title) is a top-down maze stealth game. The player's objective is to steal all the servers for a data centre, sneaking around armed guards that will chase them out. The player navigates through obstacles while also avoiding cameras and janitors that can signal the player's location to the guards. Once all servers are nabbed, the game turns into a fast escape with more obstacles and permanently alerted guards.

# Way of Working
- Assign yourself the corresponding ticket in Jira and set it to In Progress
- Create a feature branch for the new work item
- Avoid creating unnecessary dependencies
- When the work is done, raise a PR
- Review, resolve conflicts, and merge PRs together in weekly meetings
- If the PR cannot wait (ex.: blocking someone else), then propose it in the discord before merging
- Close the corresponding Jira after the PR is merged
